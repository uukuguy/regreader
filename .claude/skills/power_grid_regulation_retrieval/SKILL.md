# 电网调度规程文件检索 Skill

## 何时使用此 Skill

当用户查询涉及以下内容时，自动激活此 Skill：
- 设备故障处理（如母线失压、保护装置动作）
- 操作规程查询（如倒闸操作、设备检修）
- 安全规定查询（如安全距离、防护措施）
- 规程条款解读（如章节内容、注释说明）

## 业务概念词汇表

- **安规**：电力安全工作规程
- **稳规**：电力系统安全稳定导则
- **母线失压**：母线电压异常降低或消失
- **保护装置**：继电保护和安全自动装置
- **注释**：规程中的补充说明（如"注1"、"注2"）
- **章节编号**：如"2.1.4.1.6"表示第2章第1节第4小节...

## 工作流程

### Step 1: 了解规程结构
使用 `get_toc` 工具获取规程目录，了解章节组织。

### Step 2: 搜索相关章节
使用 `smart_search` 工具搜索关键词，定位相关章节。

### Step 3: 读取详细内容
使用 `read_page_range` 工具读取搜索结果对应的页面内容。

### Step 4: 查找注释说明
如果内容中提到"注X"，使用 `lookup_annotation` 工具查找注释详情。

### Step 5: 查找相关表格
如果涉及数据标准，使用 `search_tables` 工具查找相关表格。

## 输出格式

按以下结构组织回答：

1. **故障/问题判断标准**
2. **应急处理步骤**
3. **恢复操作流程**
4. **相关注释和表格引用**
5. **来源标注**（章节号 + 页码）

## 示例

用户查询："母线失压如何处理？"

输出：
```
母线失压处理流程：

1. 故障判断标准
   - 母线电压低于额定电压的80%
   - 持续时间超过2秒
   - 相关保护装置动作

2. 应急处理步骤
   - 立即切断非重要负荷
   - 检查备用电源状态
   - 启动应急预案

3. 恢复操作流程
   - 确认故障原因已排除
   - 逐步恢复负荷供电
   - 记录故障处理过程

来源：安规 第6章 母线失压处理，第45-47页
```
